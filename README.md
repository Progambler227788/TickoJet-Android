# 🎟️ TickoJet - Event Ticket Booking Android App

**TickoJet** is a sleek and user-friendly Android app built with a Spring Boot backend. It allows users to explore trending events, book tickets, and pay securely using Wallet or Stripe. Users can manage profiles, filter events, and enjoy a smooth mobile experience.

---

## ✨ Features

- 🔥 View **Trending Events**
- 🏷️ **Filter Events** by category
- 🛒 **Book Tickets** easily
- 💳 Pay using **Wallet** or **Stripe**
- 🙋‍♂️ Update **User Profile**
- 📱 Responsive and intuitive UI

## 🛠️ Tech Stack

- **Frontend:** Android (Kotlin, XML)
- **Backend:** Spring Boot (REST API)
- **Database:** Mongodb
- **Payments:** Stripe, Wallet integration
- **Image Loading:** Glide
- **Architecture:** MVVM + Repository pattern
